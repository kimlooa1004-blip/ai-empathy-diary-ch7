# PRD — AI 공감 다이어리

작성: product-manager 역할 / 범위: **1단계(로그인 없음)**

## 1. 무엇을 만드는가

하루에 있었던 일을 한 줄로 적으면, AI가 감정과 강도를 매기고 공감 한마디를 돌려주는
웹 앱이다. 글은 서버에 저장되어 다시 볼 수 있고, 위기 표현이 보이면 상담 연락처를
함께 띄운다.

## 2. 누가 쓰는가

- 하루를 짧게 기록하고 싶은 사람. 길게 쓰는 일기는 부담스러워 미루게 되는 사람.
- 1단계는 로그인이 없으므로 **내 컴퓨터에서 혼자 쓰는 앱**이다. 여럿이 함께 쓰는 것은 2단계다.

## 3. 성공의 모습

한 줄을 쓰고 보내면 몇 초 안에 감정 라벨과 공감 한마디가 뜬다. 서버를 껐다 켜도 기록이
남아 있다. AI가 실패하면 실패했다고 보인다.

## 4. 기능

| 번호 | 기능 | 내용 | 이렇게 되면 끝난 것 |
|---|---|---|---|
| F1 | 한 줄 일기 쓰기 | 1~200자. 글자수를 세어 보여 주고, 빈 글과 초과 글은 거절한다 | 201자를 넣으면 보내기가 막히고 안내가 뜬다 |
| F2 | 감정 분석 | 기쁨·슬픔·분노·불안·평온 중 하나와 강도 1~5 | 일기를 쓰면 감정과 강도가 함께 뜬다 |
| F3 | 공감 메시지 | 한국어 한두 문장. 진단하거나 가르치지 않는다 | 감정 아래에 공감 한마디가 뜬다 |
| F4 | 지난 기록 보기 | 날짜별로 묶어 최신순으로 나열한다 | `/history`에 쓴 글이 날짜별로 보인다 |
| F5 | 위기 안내 | 자해·극단적 선택 표현이 보이면 상담 연락처를 **공감 메시지와 함께** 띄운다 | "다 그만두고 싶다"를 쓰면 상담 연락처가 뜬다 |
| F6 | 기록 삭제 | 기록 하나를 지운다 | 지우기를 누르면 목록에서 사라지고 서버에도 없다 |
| F7 | 실패를 숨기지 않기 | AI가 실패해도 일기는 저장하고 `분석하지 못함`으로 적는다 | 키 없이 띄워도 글은 저장되고 안내가 다르게 뜬다 |

## 5. 범위 밖 (1단계)

- 구글 로그인과 사용자별 분리 → **2단계**
- Supabase Postgres 저장과 Vercel 배포 → **2단계**
- 기록 **수정**(삭제 후 다시 쓰기만 지원)
- 감정 통계, 그래프, 달력 보기
- 여러 줄 일기, 사진 첨부, 알림

## 6. 하지 말아야 할 것

- **AI가 실패했는데 공감한 척하기.** 아무 감정이나 찍지 않는다.
- **진단처럼 보이기.** 이 앱은 상담 도구도 진단 도구도 아니다.
- **위기 신호를 조용히 넘기기.** 놓치는 것보다 오탐이 낫다.
- **일기가 외부로 나간다는 사실을 숨기기.** 화면에 보이는 경고를 둔다.

## 8. 사용자가 직접 해야 하는 일

1. `.env`에 `OPENROUTER_API_KEY`를 넣는다(6장 `.env`에서 복사).
2. 1차 모델이 무료 목록에서 빠졌으면 `.env`의 `OPENROUTER_MODEL`을 바꾼다.
3. 2단계에서는 Supabase `DATABASE_URL`과 구글 OAuth 값을 준비한다.
